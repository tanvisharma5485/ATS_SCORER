# SentenceTransformer based on sentence-transformers/all-mpnet-base-v2

This is a [sentence-transformers](https://www.SBERT.net) model finetuned from [sentence-transformers/all-mpnet-base-v2](https://huggingface.co/sentence-transformers/all-mpnet-base-v2). It maps inputs to a 768-dimensional dense vector space and can be used for semantic textual similarity, semantic search, paraphrase mining, classification, clustering, and more.

## Model Details

### Model Description
- **Model Type:** Sentence Transformer
- **Base model:** [sentence-transformers/all-mpnet-base-v2](https://huggingface.co/sentence-transformers/all-mpnet-base-v2) <!-- at revision e8c3b32edf5434bc2275fc9bab85f82640a19130 -->
- **Maximum Sequence Length:** 384 tokens
- **Output Dimensionality:** 768 dimensions
- **Similarity Function:** Cosine Similarity
- **Supported Modality:** Text

### Full Model Architecture

```
SentenceTransformer(
  (0): Transformer({'transformer_task': 'feature-extraction', 'modality_config': {'text': {'method': 'forward', 'method_output_name': 'last_hidden_state'}}, 'module_output_name': 'token_embeddings', 'architecture': 'MPNetModel'})
  (1): Pooling({'embedding_dimension': 768, 'pooling_mode': 'mean', 'include_prompt': True})
  (2): Normalize({'module_input_name': 'sentence_embedding', 'module_output_name': 'sentence_embedding'})
)
```

## Usage

### Direct Usage (Sentence Transformers)

First install the Sentence Transformers library:

```bash
pip install -U sentence-transformers
```
Then you can load this model and run inference.
```python
from sentence_transformers import SentenceTransformer

# Download from the 🤗 Hub
model = SentenceTransformer("sentence_transformers_model_id")
# Run inference
sentences = [
    'Sales Manager with 1 years of experience based in Toronto. MBA. Previously at Lumen and Northwind, where I helped to forecast revenue and report on sales metrics, develop relationships with key accounts, and manage and grow a book of business. Core skills include cold outreach, pipeline management, B2B sales, lead generation, and account management. Proven track record of delivering results in fast-paced environments and collaborating across teams to drive measurable impact.',
    'Fathom is hiring a Business Development Manager (Singapore). In this role you will negotiate and close deals with new clients, exceed quarterly sales targets, manage and grow a book of business, and develop relationships with key accounts. We are looking for 4+ years of experience and strong skills in account management, cold outreach, Salesforce, pipeline management, CRM, and closing. You should be a collaborative team player who thrives on ownership and impact.',
    'Acme Corp is hiring a Cloud Engineer (New York). In this role you will ensure security and scalability of platforms, build and maintain CI/CD pipelines, reduce incident response time and toil, and improve system reliability, monitoring, and alerting. We are looking for 2+ years of experience and strong skills in monitoring, Prometheus, CI/CD, Ansible, and AWS. You should be a collaborative team player who thrives on ownership and impact.',
]
embeddings = model.encode(sentences)
print(embeddings.shape)
# [3, 768]

# Get the similarity scores for the embeddings
similarities = model.similarity(embeddings, embeddings)
print(similarities)
# tensor([[1.0000, 0.8305, 0.1158],
#         [0.8305, 1.0000, 0.0823],
#         [0.1158, 0.0823, 1.0000]])
```
